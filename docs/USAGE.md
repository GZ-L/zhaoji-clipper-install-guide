# 使用说明

兆基 Clipper 的主要用途是把网页资料剪藏为 Markdown，并保存到 Obsidian 或飞书知识库。

## 首次配置

安装扩展后，先打开扩展设置页，配置保存方式。

### Obsidian 协议保存

适合最快上手。

需要准备：

- 本机已安装 Obsidian。
- 已有一个 Obsidian 仓库。
- 知道仓库名称。

配置方式：

1. 打开扩展设置。
2. 选择 `obsidian://` 保存方式。
3. 填写 Obsidian 仓库名。
4. 设置默认保存目录和文件名模板。

### Obsidian Local REST API

适合更稳定的长期使用，尤其是长文、图片、本地文件夹归档。

需要准备：

- Obsidian 已安装 Local REST API 插件。
- Local REST API 插件已启用。
- 已生成 API Key。
- 本机接口地址可用，例如 `http://127.0.0.1:27123`。

配置方式：

1. 打开扩展设置。
2. 选择 Local REST API 保存方式。
3. 填写 API 地址和 API Key。
4. 保存设置。
5. 用普通网页测试一次剪藏。

### 飞书知识库

v4.0.0 支持可选保存到飞书知识库。

需要准备：

- 飞书开放平台自建应用。
- App ID 和 App Secret。
- 已配置 OAuth 回调地址。
- 应用权限包含文档导入、云文档和知识库相关权限。
- 当前飞书账号对目标知识库有写入权限。

飞书保存是可选功能。不配置飞书时，默认仍然可以只保存到本地 Obsidian。

## 剪藏网页

常用入口：

- 点击 Chrome 工具栏中的扩展图标。
- 使用快捷键 `Command + Shift + S`。
- 在网页中右键，选择兆基 Clipper 相关菜单。

剪藏流程：

1. 打开想保存的网页。
2. 触发剪藏。
3. 在弹窗里检查标题、正文和标签。
4. 必要时手动编辑 Markdown。
5. 选择保存目标。
6. 点击保存。

## 选区剪藏

如果只想保存网页中的某一段：

1. 先用鼠标选中网页文字。
2. 再点击扩展图标或使用快捷键。
3. 弹窗会优先使用选中的内容。
4. 确认后保存。

## 完整抓取

对于长文、长 thread 或需要滚动加载的页面，可以在弹窗中使用完整抓取入口。完整抓取会尝试滚动页面并收集更多正文内容。

如果目标平台对登录态、图片防盗链、字幕接口或动态加载有限制，结果可能需要手动检查。

## 高亮

扩展支持网页划词高亮。选中文字后，可以通过浮动按钮或快捷键保存高亮。高亮数据保存在当前浏览器本地扩展存储中。

## 建议工作流

推荐流程：

1. 普通网页先用默认剪藏。
2. 长文或 thread 使用完整抓取。
3. 保存前检查标题和 frontmatter。
4. 对需要复盘的内容添加固定标签。
5. 进入 Obsidian 后交给下游整理、总结或知识库 agent 继续处理。

扩展本身定位是 capture-only，也就是只负责精准捕获和保存，不负责 AI 摘要、改写和分类。
