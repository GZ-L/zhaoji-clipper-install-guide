# 效果说明

兆基 Clipper 的实际效果取决于网页类型、登录状态、平台限制和保存方式。下面是可预期的效果和边界。

## 典型输出

保存到 Obsidian 后，通常会得到一个 Markdown 文件。内容可能包含：

- 标题。
- 来源 URL。
- 作者。
- 发布时间。
- 标签。
- 正文 Markdown。
- 图片链接或本地图片引用。
- 平台相关的附加信息。

具体字段取决于网页内容和扩展设置。

## 适合的场景

适合：

- 中文文章剪藏。
- 知识库资料归档。
- Obsidian 长期资料库建设。
- B 站、YouTube、小红书、微信公众号、X/Twitter、飞书文档等平台内容整理。
- 先捕获原始资料，再交给 Obsidian 或 agent 做二次处理。

不适合：

- 自动生成 AI 总结。
- 自动改写文章。
- 自动分类知识库。
- 绕过平台权限、付费墙或登录限制。
- 保存没有访问权限的私有内容。

## v4.0.0 重点效果

v4.0.0 的重点是扩展保存目标：

- 默认仍然支持保存到本地 Obsidian。
- 可选保存到飞书知识库。
- 飞书保存需要用户自己的飞书自建应用和 OAuth 授权。
- 凭证和 token 保存在本机浏览器扩展本地存储中。

## Markdown 效果

相比手动复制粘贴，使用剪藏扩展通常能获得：

- 更干净的正文。
- 更稳定的 Markdown 层级。
- 更完整的来源信息。
- 更少的推荐内容、评论和侧栏干扰。
- 可复用的标签和 frontmatter。

但它不能保证每个网站都百分百完美。复杂网页可能需要保存前手动检查。

## 图片效果

图片保存效果取决于保存方式：

- `obsidian://` 方式更轻量，但对超长内容和图片落地能力有限。
- Local REST API 更适合长文和本地图片保存。
- 部分平台图片可能因为登录态、反盗链或跨域策略无法完整下载。

## 飞书效果

飞书知识库保存适合把剪藏内容转成飞书文档并归档到指定知识库节点。公网图片通常更容易导入，登录后才能访问的图片可能受飞书导入能力限制。

## 隐私效果

默认 Obsidian 保存方式是本地优先。只有当你主动配置飞书，并点击保存到飞书知识库时，剪藏内容才会上传到你自己的飞书知识库。

扩展开发者不提供中转服务器。本仓库也不保存任何 API Key、App Secret、OAuth token 或用户资料。
